Programa un descuento global para WooCommerce sin modificar los precios guardados de los productos.

== Description ==

Descuento Global Woo permite a administradores y Shop Managers configurar una campaña para toda la tienda.

La fecha inicial y la fecha final son opcionales. El descuento se calcula dinámicamente desde el precio regular, funciona en catálogo, carrito y checkout, y restaura las ofertas originales al finalizar.

== Installation ==

1. Sube la carpeta del plugin a `/wp-content/plugins/`.
2. Activa el plugin desde el panel de WordPress.
3. Abre WooCommerce > Descuento global.
4. Configura el porcentaje y, si lo necesitas, las fechas de la campaña.
